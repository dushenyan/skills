# 六类提问法

苏格拉底式提问的经典分类，是所有场景共享的武器库。每轮从最贴近用户当前处境的一类里取 1～2 个问题，不铺开轮询。

## 使用

| 类别 | 目的 | 适用时机 |
|------|------|---------|
| 澄清概念 | 把模糊词变清楚 | 用户用了含义不明的关键词 |
| 检验假设 | 挖出没说出口的前提 | 用户的推理依赖隐含前提 |
| 探究证据 | 检查支撑的来源与强度 | 用户给出了理由或数据 |
| 换位视角 | 看到其他立场的合理性 | 用户只站在一个角度 |
| 推演后果 | 沿着逻辑走到尽头 | 用户的观点成立后意味着什么 |
| 反思元问题 | 检验问题本身 | 用户可能在问错问题 |

各类示例句式：

**澄清概念**
- 「你说『稳定』的时候，具体指什么？是收入、职位，还是心理状态？」
- 「如果把这句话里的『X』换成具体场景，你会怎么描述？」
- 「这个问题里，哪个词的含义你最没把握？」

**检验假设**
- 「这个结论背后，你默认了什么前提？」
- 「如果这个前提不成立，会发生什么？」
- 「你是因为它是对的才相信它，还是因为希望它是对的？」

**探究证据**
- 「你这么判断的依据是什么？是亲身经历、道听途说，还是推理？」
- 「有没有出现过和这个结论相反的情况？当时你怎么解释的？」
- 「如果要说服一个怀疑的人，你手上最硬的证据是哪一条？」

**换位视角**
- 「一个和你利益完全相反的人，会怎么看你这个选择？」
- 「有没有人用完全不同的思路处理过同样的问题？他们图什么？」
- 「如果把你最信任的朋友放到这个位置，你会给他什么建议？」

**推演后果**
- 「沿着这个决定走下去，一年后最可能的一天是什么样？」
- 「最坏的情况发生了，你能接受到什么程度？」
- 「这个选择排除了哪些别的可能？它们里有没有你其实更在乎的？」

**反思元问题**
- 「你在问『该不该跳槽』，但你真正纠结的是跳槽本身，还是别的什么？」
- 「为什么是现在问这个问题？一个月前的你会问它吗？」
- 「如果这个问题消失不了，你会怎么和它共存？」

## 要点

- 六类不按顺序走，按用户的处境挑。
- 连续两轮用同一类问题，说明钻牛角尖了，换一类。
- 「反思元问题」最锋利也最容易冒犯，只在信任建立后（通常第三轮之后）使用。
- 每个问题都要能接住用户的回答继续问下去，一次性问题不要问。
