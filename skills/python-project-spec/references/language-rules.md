# 主语言标识（写入项目规则文件）

本文件覆盖 Skill 的「七、主语言标识（写入项目规则文件）」。

## 七、主语言标识（写入项目规则文件）

项目以 **中文** 为主语言。必须将主语言声明写入**项目规则文件**（`.trae/rules.md`），供 AI Agent 读取并约束后续行为。不使用独立的 `LANGUAGE.md`。

### 7.1 写入位置

`.trae/rules.md`（若无该文件则新建）

### 7.2 声明内容模板

在 `.trae/rules.md` 顶部或「全局规则」章节加入以下段落：

```markdown
## 全局规则

1. **本项目主语言为中文（Simplified Chinese）**
   - 所有代码注释（函数 docstring、行内注释、类注释）必须使用中文
   - 项目文档（docs/ 目录、README 等）必须使用中文撰写
   - Git 提交信息（commit message）默认使用中文
   - 与 AI Agent 的交互输出、用户端文案优先使用中文
   - 仅在必须与第三方库/标准保持一致时使用英文命名或术语
```

### 7.3 设计说明

- 选择 `.trae/rules.md` 而非独立文件，是因为 TRAE 的 Agent 在每次会话中会自动加载该规则文件
- 集中管理避免规则分散（主语言、命名规范、编码风格可统一放在 rules.md 中维护）
