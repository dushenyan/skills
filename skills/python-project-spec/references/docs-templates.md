# docs 文档目录规范

本文件覆盖 Skill 的「五、docs 文档目录规范」。

## 五、docs 文档目录规范

项目根目录下必须创建 `docs/` 目录，并包含以下 7 份文档（缺一不可）：

```
docs/
├── 01_项目背景文档.md      # 项目来源、业务痛点、目标用户
├── 02_项目实施文档.md      # 技术选型、开发流程、里程碑计划
├── 03_项目运维文档.md      # 部署方式、监控告警、故障排查流程
├── 04_项目面试点.md        # 核心技术点、常见面试题、深度问题清单
├── 05_架构设计.md          # 系统架构图、模块职责、数据流说明
├── 06_可运行项目文档.md    # 快速启动步骤、依赖安装、Demo 演示指南
└── 07_能力目标扩展.md      # 未来演进方向、可拓展功能、性能优化思路
```

### 文档设计思路

- 编号前缀确保阅读顺序与项目生命周期一致（背景 → 实施 → 运维 → 扩展）
- `04_项目面试点.md` 帮助复盘项目核心价值，面向求职或技术分享场景
- `06_可运行项目文档.md` 让新成员在 5 分钟内跑通项目
