# 文本

中英文混排的字间距、句式和风格规则，是全规范最高频的一节。

## 使用

**字间距**

```
错误：本文介绍如何快速启动Windows系统。
正确：本文介绍如何快速启动 Windows 系统。
```

数字与中文之间加不加空格皆可，全篇统一即可：`2011 年 5 月` 或 `2011年5月`。
英文单位前的数字留空隙：`16 GB 的智能手机`。半角字符与全角标点之间不留空格：`他的电脑是 MacBook Air。`

**句子**

- 不含标点的单句 ≤20 字最佳；20～29 字可接受；30～39 字须语义明确；40 字以上禁止。
- 逗号分割的长句 ≤100 字或 3 行。
- 优先简单句和并列句，避免复合句：`他昨天生病了，没有参加会议。` 好于 `那个昨天生病的人没有参加会议。`
- 用肯定句：`请确认装置的电源已关闭。` 好于 `请确认没有接通装置的电源。`
- 避免双重否定：`用户必须拥有删除权限，才能删除此文件。`

**写作风格**

- 主动语态优先：`假如尚未安装这个软件`，不是 `假如此软件尚未被安装`。
- 不用冷僻、生造、文言词语；用对的、地、得。
- 代词（其、该、此、这）必须指代明确且唯一。
- 名词前不堆形容词。

**英文处理**

- 英文复数翻译时还原单数：`随机存取存储器（RAM）`。
- 中文语境用中文省略号 `⋯⋯`，不用 `...`。
- 英文书名翻译后用书名号：`《航空业的未来》`。
- 英文词汇首次出现加中文标注：`IOC（International Olympic Committee，国际奥林匹克委员会）`，之后直接用缩写。
- 专有名词首字母大写，非专有名词（如 `online transaction processing`）不大写。

## 要点

- 中英文之间加半角空格是本规范的招牌规则，校对时第一个查它。
- 长句拆分优先拆成并列短句，不靠逗号硬连。
