# 数值

数字的书写规范。

## 使用

- 阿拉伯数字一律半角：`1000 元`，不是 `１０００元`。
- 千位以上加千分号（半角逗号）：`￥1,258,000`。4 位数可加可不加，4 位以上必须加。
- 货币：数字前加货币符号（`$1,000`），或数字后写中文名称（`1,000 美元`）。
- 数值范围用 `～` 或 `—`，两边都带单位或百分号：`132 kg～234 kg`、`67%～89%`。
- 时间用半角冒号：`早上 8:00`。

**变化程度**：「了」表增量，「到」表定量：

```
增加到过去的两倍（过去为一，现在为二）
增加了两倍（过去为一，现在为三）
降低到百分之八十（原来一百，现在八十）
降低了百分之八十（原来一百，现在二十）
```

禁止「降低 N 倍」的写法（降低一倍等于零），改用「降低百分之几」。

## 要点

- 增减表述是最容易写错语义的地方，改稿时单独过一遍数字段落。
