# 段落

段落组织和引用标注规则。

## 使用

**段落原则**

- 一个段落只有一个主题，或一个中心句子。
- 中心句放段首，概述全段；后面的句子为中心句服务。
- 段落不超过七行，最佳 ≤4 行。
- 用陈述语气，避免感叹语气。
- 段落之间用一个空行隔开，段首不留空白字符。

**引用第三方内容**

注明出处：

```
One man's constant is another man's variable. — Alan Perlis
```

全篇转载时，在开头显著位置注明作者和出处，并链接原文：

```
本文转载自 WikiQuote
```

使用外部图片时，在图片下方或文末标明来源。

## 要点

- 中心句前置是最能提升可读性的一条，写完一段先检查第一句。
- 超过七行的段落，几乎总能按「一个主题」拆成两段。
