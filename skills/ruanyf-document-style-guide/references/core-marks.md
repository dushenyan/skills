# 标点符号

全角优先原则与各标点的易错点。

## 使用

**总原则**

- 中文语句用全角标点，保持视觉一致。
- 整句为英文时，该句用半角标点。
- 句号、问号、叹号、逗号、顿号、分号、冒号不得出现在一行之首。

**顿号**

并列词用全角顿号 `、`，不用逗号，并列词是英文也一样：

```
错误：Google, Facebook, 腾讯, 阿里和百度等。
正确：Google、Facebook、腾讯、阿里和百度等。
```

**括号**

补充说明用全角圆括号 `（）`，括号前后不加空格：`所有的连接（电缆和接插件）均安装牢固`。

**冒号**

引出解释用全角 `：`；表示时间用半角 `:`，如 `早上 8:00`。

**省略号**

占两个汉字、六个点，用 `⋯⋯`，不用 `...` 或 `。。。`。省略号不与「等」连用：`香蕉、苹果、梨等各色水果`。

**引号**

引用用全角双引号，内层用单引号：`鲍勃解释道："我要放音乐，可萨利说，'不行！'。"`

**破折号与连接号**

- 破折号占两个汉字位置，用于进一步解释。
- 名词复合、图表编号用半角直线 `-`：`氧化-还原反应`、`图 1-1`。
- 数值范围用波浪号 `～` 或一字线 `—`：`2009 年～2011 年`，前后都建议带单位。

**感叹号**

平静叙述，尽量避免感叹号，禁止连用。

**图形符号**

表示「对/错」「通过/失败」「支持/不支持」时，用轻量的文本符号，不用带底色的 emoji：

```
错误：✅ 支持    ❌ 不支持
正确：✔ 支持    ✘ 不支持
```

`✅`、`❌` 是彩色 emoji，在不同渲染环境下粗细、颜色不一，容易抢正文视觉；`✔`、`✘` 是普通字符，与中文排版更协调。列表、表格、对照说明优先用文字（「支持」「不支持」）表达，符号仅作辅助。

## 要点

- 校对优先级最高的三处：中英文空格、全半角混用、顿号当逗号用。
- `...` 改 `⋯⋯` 是中文文档最常见的迁移错误。
- 对错、通过失败一类的标记用 `✔`、`✘`，不用 `✅`、`❌`。
