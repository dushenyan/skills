# 叙事风格

排版管「看起来」，风格管「读起来」。阮一峰的文字好读，靠的是几件很朴素的事：先讲问题再讲方案、句子短、给类比、偶尔说一句「我」。写讲解性文字时带着这个手感。

## 使用

**问题驱动，先痛点后方案**

讲新概念前，先讲它解决什么问题，再给方案。经典句式：「如果你想 X，但 Y 很难做到，那么 Z 就是答案。」

```
反例：Transformer 提出了多头注意力机制。
正例：单一注意力像个全才，什么都管，结果什么都管不好。作者想——不如雇个专家团队，各管一摊。
```

**口语化短句**

- 一句话能说清绝不用两句，多用句号，少用长从句。
- 主动句优先，多用「你」「我们」做主语，像跟朋友聊天。
- 过渡词让行文有呼吸感：其实、不过、打个比方、说到这里。

**生活化类比**

每个抽象概念配一个类比。三原则：

- **贴**：读者熟悉的场景（做饭、搬家、图书馆、快递）。
- **准**：机制真的对得上，不为形象牺牲准确。
- **短**：一两句讲完，不展开成长篇比喻。

格式：`**打个比方**：……` 或 `**想象你去图书馆查资料**：……`。写不出合适的类比就老老实实解释一遍，不硬凑。

**作者视角**

偶尔插一句自己的观察，如「我当初也是踩了坑才搞明白的」。每章最多 1～2 处，点到为止。禁止鸡汤味、煽情。

**禁用腔调清单**

| 类别 | 别用 |
|---|---|
| 学术腔 | 综上所述、由此可见、总而言之、本文将详细介绍 |
| 教材腔 | 所谓 XXX 就是、作为一个 XXX |
| 官腔 | 值得我们注意的是、需要特别强调的是 |
| 客套腔 | 本教程将带领大家 |
| 过度口语腔 | 小伙伴们、老铁们 |
| 卖课腔 | 必看！！！、非常重要！！！ |
| 空泛形容 | 极其强大、完美解决方案 |

## 要点

- 交稿前顺一遍四件事：开头在讲问题吗？有没有一两处类比？有没有一句「我」的观察？避开了禁用腔调吗？
- 内容准确、例子能跑，永远优先于风格；八九分像即可，不为对齐风格改写已经讲清楚的段落。
- 禁用腔调的本质是「这句话没讲具体」，避开的办法是把话说具体，不是换个词。
