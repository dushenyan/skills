# 参考链接

引用第三方内容时的标注规范，以及延伸阅读。

## 使用

- 引用一句话、一段话：紧跟出处，如 `One man's constant is another man's variable. — Alan Perlis`。
- 全篇转载：开头显著位置注明作者和出处，并链接原文。
- 使用外部图片：图片下方或文末标明来源。

## 要点

- 技术文档里无出处的外部引用，默认按不可信处理。
