# 标题

标题分四级：`#` 文章标题、`##` 主要部分、`###` 二级小节、`####` 更小的方面。

## 使用

结构禁忌：

```markdown
# 一级标题

### 三级标题
```
一级标题下不能直接出现三级标题，中间必须有二级标题。

```markdown
## 概述

### 概述
```
下级标题不重复上一级标题的名字。

孤立编号要避免：同级只有一个子标题时，把子标题并入父级或直接删掉。

并列内容优先用项目列表，不滥用四级标题：

```markdown
### 三级标题

**（1）A**

**（2）B**

**（3）C**
```
这个结构好于在三级标题下平铺三个四级标题。

## 要点

- 点号（句号、逗号、冒号等）不得出现在标题末尾；问号、引号可以。
- 谨慎使用四级标题，保持层级简单。
