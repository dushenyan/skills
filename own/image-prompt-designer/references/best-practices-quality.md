# 质量与校验

图的毛病理分两类：**表达层**（画面不好看、不真实）与**传达层**（看不清、看不懂）。先判断属于哪层再动手，改错层怎么调都不会好。

## 一、传达层：文字与层级

### 文字渲染：先承认模型不擅长

生成模型把文字当图形画，不是当字符排。策略是**减少字数、缩短字符串、把长解释移出画面**，而不是反复重试。

**图内只放短标签**

- 中文标签 ≤ 8 字，英文 ≤ 3 个词。
- 超过 12 字的说明改为图外图注，画面只留关键词。

**英文与中文的标注方式**

按标签密度从高到低选：

| 场景 | 做法 |
|---|---|
| 标签不密集（≤ 8 个） | 英文主标 + 下方小号中文副标，两行居中 |
| 标签较多（9~12 个） | 中文主标 + 右上角小号英文，英文缩到 60% 字号 |
| 标签密集或术语很长 | 画面只留英文缩写，完整释义放到图外图注表 |

提示词要显式写清主副关系，否则模型会把两行画成同等大小甚至重叠：

```
每个标签为两行：上行英文 Retrieval，字号较大；
下行中文「检索」，字号为上行 60%；两行居中对齐。
```

**给「无其他文字」指令**

在第 6 段末尾固定加「画面无其他文字」，并在负面约束里重复。模型自造的角落小字是最大的质量杀手。

**修不好时换方案**

同一处文字连续两次仍错，不要重试。改成画面只留图形与编号，图外配编号对照表，这比继续抽卡稳定。

### 信息层级

三个层级就够：主标题、信息块标题、说明文字。第四层读者不会读，只会觉得挤。

用三种手段同时区分，不要只靠字号：

| 手段 | 主标题 | 块标题 | 说明 |
|---|---|---|---|
| 字号 | 最大 | 中等 | 最小 |
| 字重 | 粗 | 中 | 常规 |
| 颜色 | 深色或主色 | 深色 | 中性灰 |

### 视觉动线

- 横向按 Z 字或左到右，落点放在左上或中心。
- 纵向按 F 字，重点放上半部。
- 关键数据用强调色标一次，标两处等于没强调。

### 留白

留白是层级的载体。四周至少 5%，区块间距大于区块内部间距——间距不一致，读者会误判分组。

## 二、表达层：光、材质与构图

### 光

**一条主光 + 一个方向**。写清光源位置与性质，否则模型会给你多个互相打架的阴影。

| 想要的效果 | 光源写法 |
|---|---|
| 产品干净 | 左前上方柔光箱，软阴影，无强反光 |
| 人物立体 | 侧逆光勾轮廓，正面补柔光，避免正面平光 |
| 氛围感 | 单一暖色窗光，暗部保留细节 |
| 科技感 | 冷色边缘光，环境光压暗，局部高光 |

平光是最常见的失败来源：没有明暗对比，画面会像贴纸。

### 材质

材质决定真实度，必须点名：哑光、金属、玻璃、皮革、纸张、织物、磨砂塑料。

反例：只写「一只耳机」，模型默认光滑塑料，廉价感立刻出来。
正例：`哑光黑聚碳酸酯外壳，耳罩为细纹皮革，头梁为磨砂铝`。

### 构图

- **三分法**：主体放在三分线交点上，比居中更有张力。
- **前中后景**：至少两层，前景虚化物、中景主体、远景环境，画面才有深度。
- **视线方向留白**：人物看向哪边，哪边多留空间。
- **避免居中平铺**：产品正面平放是电商白底图，不是视觉图。

### 畸变治理

生成模型最常坏在三处：手指、肢体、重复元素。

- 手部：提示词里减少手部出现，或用道具遮挡。
- 肢体：明确「全身 / 半身 / 仅上半身」。
- 重复：写「画面中只有一个人物」，并加入负面约束。

写实类图的畸变几乎无法靠提示词完全消除，实际策略是**多生成几次，挑选可用的一张**，而不是追求一次成功。

## 三、迭代策略

每次只改一个变量，并记录改了什么：

| 现象 | 改哪个变量 |
|---|---|
| 整体风格跑偏 | 第 3 段，收紧形态描述 |
| 排版拥挤 | 第 5 段减少块数，或提高留白比例 |
| 文字错乱 | 第 6 段减少标签数，或缩短字符串 |
| 颜色杂乱 | 第 7 段压缩色板，明确主色用量 |
| 画面平淡 | 第 2 段补光线方向与景别 |
| 出现多余元素 | 负面约束逐条补充，一次加一条 |

一次改五处的后果：变好了不知道为什么好，变差了也定位不到原因。

## 四、交付前验收

**通用项**

- [ ] 第一眼落在预期的主体或主标题上
- [ ] 风格单一，没有扁平与写实混用
- [ ] 配色克制，没有跑出第五种主色
- [ ] 元素无贴边、无重叠、无遮挡
- [ ] 画幅与目标载体匹配（投屏 / 手机 / 文档 / 印刷）

**信息型追加**

- [ ] 信息块数量、顺序与内容清单一致
- [ ] 图内每个字拼写正确，无乱码、无截断
- [ ] 每个英文术语都有对应中文释义，主副层级正确
- [ ] 单图标签总数 ≤ 12
- [ ] 强调色只用在一处

**表达型追加**

- [ ] 主体只有一个，且不与其他元素抢视线
- [ ] 光影方向一致，没有多光源打架
- [ ] 材质有一处可辨认的细节（纹理、反射、缝线）
- [ ] 人物无肢体畸变，手部无异常
- [ ] 细节数量适中，画面不空也不乱
- [ ] 留白足够，主体没有被裁切

验收不通过时先分层：看错字、看不懂结构 → 回 Step 2A 改内容；不好看、不真实 → 改提示词第 2、3、7 段。分不清是哪层时，先修传达层，因为一张好看的废图仍是废图。
