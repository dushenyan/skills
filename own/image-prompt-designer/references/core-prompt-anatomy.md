# 提示词结构

## 骨架

四段必写，两段按需。顺序固定，因为模型对靠前的内容权重更高，先给「画什么」和「怎么拍」，再给风格词。

```
[1 画面主体]   必写
[2 构图视角]   必写
[3 视觉风格]   必写
[4 画幅画质]   必写
[5 版式分区]   信息型必写，表达型省略
[6 图内文字]   图里要字才写，不要就明确写「画面无文字」
[7 色彩材质]   黑白或极简可省
[8 负面约束]   必写
```

六个编号是给写作者的分段依据，不是要原样贴给模型。真正提交时可以连成一段，但每段的信息一个都不能少。

## 两类图的差异

| 段落 | 信息型 | 表达型 |
|---|---|---|
| 主体 | 图的主题，如「向量数据库的三层结构」 | 画面里那一个东西，如「一只停在扳手上的麻雀」 |
| 构图 | 分区、比例、阅读顺序 | 景别、角度、留白、视线方向 |
| 风格 | 扁平矢量、线框、等距 | 摄影、胶片、油画、3D 渲染 |
| 版式 | 必写 | 省略 |
| 文字 | 常有 | 通常没有 |
| 色彩 | 色板约束严格 | 允许自然色，氛围优先 |

## 必写段怎么写

### 1. 画面主体

先给类目，再给特征。类目是最强信号，`信息图`、`架构框图`、`产品摄影`、`电影感人像` 各自会激活完全不同的构图习惯。

- 好：`一张技术信息图，主题是 RAG 检索增强生成的三段流程`
- 好：`一张产品摄影，主体是一只哑光黑的降噪耳机，斜放在浅灰水泥台面上`
- 差：`科技感、未来感、超酷的 AI 图`

### 2. 构图与视角

用可验证的方位、比例、景别描述，避免「合理」「美观」这类没有约束力的词。

- 信息型：`顶部 1/5 标题区；下方横向三等分卡片，间距相等；四周留白 8%`
- 表达型：`85mm 中景，主体置于右侧三分线，左前方 45° 侧逆光，背景虚化`
- 差：`布局要美观，元素排布合理`

需要精确控制时给网格，如 `12 列网格，卡片各占 3 列`。

### 3. 视觉风格

选一种，并给可见的形态描述。只写风格名，模型会自由发挥。

| 风格 | 形态描述要点 |
|---|---|
| 扁平矢量 | 纯色块、无阴影、2px 描边、圆角 8px |
| 等距 3D | 45° 俯角、光源统一从左上、软阴影 |
| 线框技术图 | 单色线条、等宽、节点为圆角矩形 |
| 手绘 | 轻微抖动线条、纸感纹理、马克笔上色 |
| 商业摄影 | 柔光箱主光、浅景深、干净背景、产品质感清晰 |
| 电影感 | 低饱和、冷暖对比、体积光、胶片颗粒 |
| 3D 渲染 | 全局光照、次表面散射、材质真实、无噪点 |

`高级感`、`科技感` 没有任何形态信息，换成具体描述。

### 4. 画幅与画质

| 用途 | 比例 |
|---|---|
| 投屏、发布会、banner | 16:9 横向 |
| 文档内嵌、博客头图 | 4:3 横向 |
| 手机、社交卡片 | 4:5 或 3:4 纵向 |
| 海报、封面 | 2:3 纵向 |
| 头像、图标、商品图 | 1:1 |

画质写具体维度：`主体边缘锐利、文字无锯齿、暗部保留细节`，比 `8K` 有效。

## 按需段怎么写

### 5. 版式与分区

只在信息型图里写。用方位词和数量词，不用形容词。

```
顶部 1/6 为标题区，下方纵向堆叠三层，每层等高，层间留 2% 间距。
```

### 6. 图内文字

**逐条列出**，不要写「标注各模块名称」。文字是模型最易出错的部分，必须显式给定。

```
图内文字（按层级）：
- 主标题：检索增强生成的三段结构
- 卡片标题：检索 / 增强 / 生成
- 英文副标：Retrieval、Augmentation、Generation，小号，置于中文标题下方
- 无其他文字
```

不需要文字时写 `画面无文字`，并在负面约束里重复一次，能显著减少自造水印。

### 7. 色彩与材质

给色值或明确色名，说明用在哪。

```
色板：背景 #F7F7F5，主色 #2F6BFF，辅助 #E8EEFF，强调 #FF7A45（仅用于关键数据）
材质：哑光纸面，无高光反射
```

写实摄影不必锁死色板，改为约束色调方向：`暖调、低饱和、阴影偏青`。

## 负面约束

按四类写，比堆一长串 `low quality` 有效：

```
不要：额外文字与水印、无意义的装饰小图标、元素贴边、
      多种风格混用、透视畸变、多余的手指与肢体、塑料感皮肤
```

信息型侧重：`不要渐变噪点、不要拥挤排版、不要超过五种颜色`
表达型侧重：`不要畸变、不要杂乱背景、不要过度锐化`

## 中英文提示词取舍

- **画面里没有中文**：用英文提示词，模型对英文的构图与风格词理解更准。
- **画面里有中文**：用中文提示词，并把中文字符串逐字写进第 6 段。英文提示词驱动中文渲染，出错率明显更高。
- **中英混排**：中文提示词为主，英文术语原样嵌入，并写明「英文为主标、中文为副标」的层级关系。

## 两个完整示例

**信息型**

```
一张横向技术信息图，主题是向量数据库的三层检索结构。
顶部 1/6 标题区，下方纵向堆叠三层，每层等高中通栏，层间留 2% 间距。
风格：扁平矢量，纯色块无阴影，圆角 8px。
画幅 16:9，四周留白 8%。
图内文字：主标题「向量数据库的三层检索结构」；三个层标签「索引层」「存储层」「查询层」，
每层右侧一行小号英文副标 Index / Storage / Query；无其他文字。
色板：背景 #F7F7F5，主色 #2F6BFF，辅助 #E8EEFF，文字 #1A1A1A。
不要：额外文字与水印、装饰性图标、渐变噪点、元素贴边。
```

**表达型**

```
一张产品摄影，主体是一只哑光黑的头戴式降噪耳机，斜放在浅灰水泥台面上。
85mm 中景，主体占画面右侧三分之二，左前方 45° 侧逆光，背景大面积虚化留白。
风格：商业摄影，柔光箱主光，浅景深，产品边缘锐利，材质纹理清晰。
画幅 4:5 纵向，画面无文字。
色调：冷灰为主，耳罩皮革保留暖棕，阴影偏青。
不要：额外文字与水印、杂乱道具、塑料感高光、畸变、过度锐化。
```

同一个骨架，一个填结构，一个填光影。判断该填哪套，是写提示词前最重要的一步。
